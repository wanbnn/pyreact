Installation
============

PyReact Framework requires Python 3.10 or higher.

Stable Release
--------------

Install the latest stable version from PyPI:

.. code-block:: bash

   pip install pyreact-framework

Development Version
-------------------

Install the latest development version from GitHub:

.. code-block:: bash

   pip install git+https://github.com/wanbnn/pyreact.git

Requirements
------------

PyReact Framework automatically installs the dependencies declared by the
published package for your Python version.

Verification
------------

Verify your installation:

.. code-block:: bash

   pyreact-framework --version

You should see output similar to:

.. code-block:: text

   PyReact Framework v1.2.0
